# MNNIT Student Blog Platform

A student-run blog by MNNIT Allahabad, dedicated to sharing insights on technology, education, and campus life while fostering a strong student community. 

This platform allows students to register, write articles, save drafts, manage comments, and publish their ideas to the campus community.

## 🚀 Tech Stack

**Frontend:**
* React.js (Vite)
* Tailwind CSS (Styling)
* React Router DOM (Navigation)
* Context API (State Management)
* Axios (HTTP Client)
* React Hot Toast (Notifications)

**Backend:**
* Node.js & Express.js
* MongoDB & Mongoose (Database)
* JSON Web Tokens (JWT) & bcrypt (Authentication & Security)
* Nodemailer (OTP Email Verification)
* Multer & ImageKit (Image Uploads & Storage)

**Deployment:**
* Vercel (Serverless Deployment)

## ✨ Key Features

* **Secure Authentication:** JWT-based login and signup system with encrypted passwords.
* **OTP Email Verification:** Users must verify their email via a 6-digit OTP sent through Nodemailer before accessing the platform.
* **Rich Dashboard:** A personalized user dashboard to track total blogs, drafts, and recent comments.
* **Blog Management:** Write, edit, save as draft, and publish blog posts seamlessly.
* **Optimized Image Uploads:** Direct image uploading utilizing ImageKit for automatic format optimization (WebP) and fast delivery.
* **Comment Moderation:** Writers can view, approve, or delete comments on their specific blog posts.
